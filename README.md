# 歌手比赛管理系统

一个基于 C++17 开发的命令行歌手比赛管理系统。项目围绕歌手、评委和比赛场次提供完整的录入、查询、打分、排名与持久化流程，适合作为 C++ 面向对象程序设计和数据结构课程项目。

## 功能特性

- **歌手管理**：新增、修改、删除、浏览及按姓名关键词查询歌手。
- **评委管理**：新增、修改、删除、浏览及按姓名关键词查询评委。
- **场次管理**：创建比赛、调整比赛日期、删除和查看比赛场次。
- **比赛打分**：选择参赛歌手和评委，录入 `0～100` 分的评委评分。
- **成绩排名**：按总成绩降序排列，生成比赛名次和十佳选手名单。
- **多维查询**：查看单场比赛明细，按总成绩或指定评委评分排序，并查询歌手、评委的跨场次记录。
- **数据持久化**：自动将歌手、评委、比赛及成绩数据保存到本地 CSV 文件。
- **输入校验**：校验编号、性别、日期和评分等常用输入。

## 计分规则

- 评委少于 3 人时，所有评分直接求和，并据此计算平均分。
- 评委不少于 3 人时，去掉一个最高分和一个最低分后计算总分与平均分。
- 所有选手按总分从高到低排名，前 10 名进入十佳名单。

## 技术实现

- C++17
- CMake 3.20+
- 自定义模板链表 `LinkedList<T>`
- `Person`、`Singer`、`Judge` 等面向对象模型
- CSV 文本文件持久化

## 构建与运行

### 环境要求

- 支持 C++17 的编译器，例如 GCC、Clang 或 MSVC
- CMake 3.20 或更高版本
- 建议使用支持 UTF-8 中文显示的终端

### 1. 构建项目

在项目根目录执行：

```bash
cmake -S . -B build
cmake --build build
```

使用 Visual Studio 等多配置生成器时，可指定配置：

```bash
cmake --build build --config Release
```

### 2. 准备数据并运行

程序会在**当前工作目录**中读取和写入以下文件：

- `singers.csv`
- `judges.csv`
- `matches_detail.csv`

建议将 `data/` 中的示例文件复制到可执行文件目录，再从该目录启动程序。以 Windows 单配置构建为例：

```powershell
Copy-Item data\*.csv build\
Set-Location build
.\SingerManagerSystem.exe
```

如果使用 Visual Studio Release 构建，可执行文件通常位于 `build/Release/`：

```powershell
Copy-Item data\*.csv build\Release\
Set-Location build\Release
.\SingerManagerSystem.exe
```

Linux/macOS 单配置构建示例：

```bash
cp data/*.csv build/
cd build
./SingerManagerSystem
```

> 程序会在数据发生变化时自动保存，并在选择主菜单的 `0` 退出时再次保存。若希望保留原始示例数据，请始终操作复制后的 CSV 文件。

## 使用流程

1. 进入歌手信息管理和评委信息管理，维护基础档案。
2. 新建比赛场次，并为该场比赛选择歌手和评委。
3. 运行模拟比赛，依次录入每位评委对每位歌手的评分。
4. 在比赛赛况中查看成绩明细、排名和评委评分排序。
5. 通过综合查询中心查看歌手历次成绩或评委历次打分。
6. 选择 `0` 保存数据并退出系统。

## 数据文件说明

| 文件 | 内容 |
| --- | --- |
| `singers.csv` | 歌手编号、姓名、性别、出生日期、地址、组别和获奖信息 |
| `judges.csv` | 评委编号、姓名、性别、出生日期、地址、组别和专业头衔 |
| `matches_detail.csv` | 比赛场次、参赛歌手、参评评委、逐项评分、排名和十佳名单 |

`matches_detail.csv` 使用带区段标记的文本格式组织嵌套数据。建议通过程序维护这些文件；手工编辑时应保持原有字段顺序和区段结构。

## 设计要点

- 使用 `Person` 作为歌手和评委的公共基类，复用基础人员信息。
- 使用自定义模板链表管理歌手、评委、比赛和评分记录，并实现深拷贝。
- 使用冒泡排序完成总成绩与单评委评分的降序排列。
- 将输入校验集中在 `Validator` 中，降低非法输入对交互流程的影响。
- 通过分层的 CSV 序列化格式恢复比赛中的嵌套对象与评分明细。

## 注意事项

- CSV 字段以英文逗号分隔，姓名、地址、组别、奖项和头衔中请勿输入英文逗号。
- 数据文件必须使用程序可正确读取的编码，并与终端中文编码设置保持兼容。
- 当前项目为交互式控制台程序，启动后请根据菜单编号完成操作。
